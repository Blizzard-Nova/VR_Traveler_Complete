VR TRAVELLER is a simulation project that aims to a take you back in time during the peak era of civilizations. The goal is to explore an ancient civilization in VR during its golden era and interact with it's citizens. Those citizens will give you more information, helping you visit some famous sites. This simulation was created for the tourist industry by first immersing a traveler into a simulated environment and then taking them to the actual site. In this project so far we have Birka Viking Town from Sweden and Ghandara from Pakistan.
